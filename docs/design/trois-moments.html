Ressenti
On voit un système qui tourne : les briques réelles de ton estimateur BTP apparaissent une à une, les liens se tirent, puis une impulsion y circule sans fin.
Coût
0 ko de librairie — canvas 2D, ~150 lignes. Charge GPU nulle. La boucle s'arrête dès que le hero sort de l'écran.
Repli
Mouvement réduit : le graphe fini, immobile, sans impulsion. Canvas indisponible : le texte seul.
Ce que ça fait subir
Le motif « graphe de workflow animé » est devenu un bloc de composant sur les sites de templates : sans libellés réels et sans typographie forte, il se lit comme générique. Sur téléphone, le graphe passe sous le texte et perd la moitié de sa largeur.
